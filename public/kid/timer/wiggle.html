which crack — the five you approved

each one is a whole drawing, twice — whole and cracked, the same egg — and the crack arrives as a mask between them. The break follows whichever you pick, so the two halves, how far it has to tip to level the seam, and where the lid lands all change with it. Pick one and it cracks that way every time.

who comes out — pick one, none is picked yet

it does not climb out — it is above the two shells, standing over the space it left, and it is simply there. Nothing here is a dial: it is drawn at the shells' own scale because it came out of this egg, and the gap between the shells is its own width — so picking a different one re-frames the whole landing by itself. The dashed circle is measured off the landing, not imposed on it.

the crack — when each line arrives

the lines are the drawing's own crack, uncovered along their own length. the shape is fixed — it cracks apart the same way every time, so how far each arrival reaches is set by how many there are. what is yours is when: drag a row's bar, or its red wedge in the lane under the egg.

how a change looks

how a change plays, wherever it lands. land on the beat waits for the next shove so the face turns on the rhythm; a gear change never waits.

versions — four rolls of the same shape

each row is one whole run, left to right, with the seconds under each face. what stays the same is the shape — a happy pop or two in the opening, most of the changes through the middle, the two shocked beats at the end, and a return to that phase's resting face after each one. what rolls is only which face fills each slot. tap a row to load it and it becomes yours to edit.

the resting face — what each phase settles back to

tap one, then tap a face in the library to change it. every pop returns to the resting face of whichever phase it lands in — so the calm it comes back to escalates too. the gentle one is the kid's own pick below.

what the kid can pick from

it always opens on a smiley — these are the smiley variations offered when they press play. tap to include or drop one.

where the gears change

“bigger in last” is real seconds, not a share of the clock — set 10s and it is the last ten whether the timer is one minute or one hour. If the whole timer is shorter than that, it shakes hard the entire way.

A gear changes on the exact second, picking up the new rhythm wherever the egg already is — it grows mid-wobble, it never stops and restarts. “gear change” is how long it takes to grow into the new size.
